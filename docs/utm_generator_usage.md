# Генератор UTM-меток — как пользоваться

Инструмент внутри приложения `marks`: собрать метку из справочника, получить полную/короткую
ссылку, видеть клики. Кривую метку собрать нельзя.

## Доступ

- Роли: `admin`, `manager`, `marketer` (оператор ботов `bot_user` — нет).
- В меню — пункт **«Метки»**.
- Маршруты: `/marks/` (реестр), `/marks/new/` (генератор), `/s/<code>/` (редирект короткой ссылки).

## Подготовка: залить справочник (один раз / при обновлении)

Значения выпадающих списков берутся из справочника UTM. Разовый импорт из CSV в репозитории:

```bash
python manage.py import_utm_dictionary
```

Загрузит: 11 medium, 46 source (в т.ч. шаблоны), 6 тип, 6 направление, 11 воронка.
Обновить справочник — положить свежие CSV в `marks/fixtures/utm_dictionary/` и повторить команду
(либо настроить авто-sync, см. ниже).

## Создать метку

1. **«Метки» → «+ Новая метка»** (`/marks/new/`).
2. **Ссылка** — вставь целевой URL (лендинг/канал/бот/ролик), напр. `https://el-ed.ru/oge`.
   Кириллица и пробелы в URL не пройдут.
3. **source / medium / тип / направление / воронка** — выбери из списков. Вписать своё нельзя.
4. **имя кампании** — впиши сам: латиница, цифры, дефис; без пробелов и `_`
   (`_` рвёт campaign, поэтому запрещён).
5. **term** (обязательно) и **content** (ID объявления) — по образцу; можно `:` и плейсхолдеры
   `{ad_id}`, `{keyword}` — они сохранятся буквально.
6. Кнопка:
   - **Полная ссылка** — целевой URL + UTM-query.
   - **Короткая ссылка** — то же, но за коротким кодом на нашем домене (`/s/<code>/`), со счётчиком.
7. Метка падает в реестр: campaign, автор (из авторизации), дата, клики.

`campaign` собирается автоматически: `тип_направление_воронка_имя` (напр. `acq_oge_bot_pyweek2026`).

### Шаблонные source (блогеры/преподы/партнёры)

Выбери в списке шаблон (`tg-<имя>`, `<partner>`, `<teacher>`, `ig-<имя>`, `yt-<имя>`, `max-<имя>`),
затем впиши имя в поле **«имя для шаблонного source»** (напр. `python2026` → `tg-python2026`).
Такая метка помечается **«на заявку Грише»** (`pending_review`).

### Дубли

Если та же ссылка с тем же набором UTM уже есть — вернётся существующая запись, дубль не создаётся.
Если просил короткую, а у существующей её не было — короткая до-создастся и прикрепится.

## Реестр

`/marks/` — все метки в одной таблице. Возможности:

- **Фильтры:** автор, source, направление, campaign (подстрока), даты с/по.
- **Клики** — счётчик переходов по короткой ссылке (растёт автоматически). Кнопка «Обновить клики»
  просто перечитывает текущие значения (внешнего источника нет — счётчик наш).
- **Экспорт в Excel** — выгружает то, что видно с учётом фильтров.

## Клики: как считаются

Короткая ссылка `/s/<code>/` при переходе делает 302 на полный URL и увеличивает счётчик в нашей БД.
Никакой внешней системы. Активации внутри бота (вход по `start`-параметру) — это отдельная аналитика
платформы, в этот инструмент не входит.

## Авто-sync справочника (для боевого режима)

Чтобы справочник обновлялся сам из Google Sheet:

1. Опубликуй вкладки 02/03/04 как CSV (Google Sheets → Файл → Опубликовать в интернете → CSV на вкладку).
2. Впиши ссылки в `.env`:
   ```
   UTM_DICTIONARY_MEDIUM_CSV_URL=...
   UTM_DICTIONARY_SOURCE_CSV_URL=...
   UTM_DICTIONARY_CAMPAIGN_CSV_URL=...
   ```
3. Запуск вручную: `python manage.py sync_utm_dictionary`.
4. По расписанию: поставь `scripts/sync_utm_dictionary.sh` в cron (напр. раз в час).

Значения, исчезнувшие из справочника, помечаются неактивными и пропадают из списков.

## Короткий домен

Сейчас короткие ссылки на `automarks.tw1.ru/s/<code>`. Нужен брендовый (напр. `l.el-ed.ru`) —
поменять `SHORTLINK_BASE_DOMAIN` в `.env` (плюс направить сабдомен на сервис на уровне DNS/деплоя).

## Админка

`/admin/` → Short links, Utm dictionary entries, Marked links — просмотр/правка вручную.
